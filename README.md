# NISP 刷题小程序

一个纯前端的 NISP（国家信息安全水平考试）刷题网站。  
参考驾考宝典的交互与布局风格，**与驾考无关**，仅复用"题库 + 顺序/随机/章节/模拟考试/错题/收藏"这一类通用刷题模式。

---

## 一、功能一览

| 模块 | 说明 |
|---|---|
| 🏠 首页 | 今日答题数 / 正确率 / 连续天数 / 最高分，入口卡片 |
| 📚 章节练习 | 6 个章节分别作答，支持单章选择 |
| 🔀 随机练习 | 题库内全随机抽题 |
| 📝 顺序练习 | 按题号顺序逐题作答，记录进度 |
| 🧪 模拟考试 | 50 题 / 30 分钟，90 分及格，自动计时交卷 |
| ❌ 错题本 | 自动收集所有答错的题目，支持移除 / 清空 / 重练 |
| ⭐ 收藏 | 重点题目收藏，支持移除 / 清空 / 重练 |
| 📊 学习统计 | 累计 / 今日 / 连续天数 / 最高分 / 考试历史 |
| 📋 答题卡 | 大题量答题卡，已答 / 未答 / 当前 / 答错状态可视
| 🔐 用户登录 | 注册 / 登录，按压反弹按钮，30 天免登录，数据同步到 MySQL

## 二、答题交互规则

### 单选 / 判断题

| 情况 | 行为 |
|---|---|
| ✅ **答对** | 弹出绿色 toast「✓ 答对了」，约 0.5 秒后**自动跳到下一题**，不展示解析 |
| ❌ **答错** | **停留在当前题**，展示解析块（标红你的选项、标绿正确答案 + 解析文字），并**自动加入错题本**；点底部「下一题」继续 |
| 📌 最后一题答对 | 直接进入练习完成页 |

### 多选题

1. 点击选项可多选（再次点击取消），**不会立即判分**
2. 选完后点底部「**确认答案**」按钮判分
3. 判对 → toast + 自动跳下一题；判错 → 停留显示解析 + 入错题本

### 模拟考试

考试模式下**不即时判分**。所有题目作答后交卷（或时间到自动交卷）统一评分，
答错与未作答的题目一并计入错题本，并保存考试记录。

### 题目回看与跳转

- **滑动切换**：练习页支持触摸滑动——**右滑 = 上一题，左滑 = 下一题**（最后一题左滑不触发交卷，防误操作）；PC 端可用 **← / → 方向键**
- **底部操作栏**：所有练习模式固定为「‹ 上一题 / 题目列表 / 下一题 ›」三键（多选未确认时中键为「确认答案」）
- **题目列表**：点「题目列表」从底部弹出题号网格——绿 = 答对、红 = 答错、灰 = 未答、描边 = 当前题；点任意题号直接跳转，点遮罩或 × 关闭
- **回看已答题**：答对的题滑回 / 跳回后会显示绿色「✓ 回答正确」解析块，答错显示红色「✗ 回答错误」，均标注正确答案与解析
- 顺序练习中以上操作均会**自动保存进度**，退出后可续做

### 导航

- 练习 / 考试 / 答题卡页面会**隐藏底部导航栏**，改用页面底部操作栏；
  此时标题栏左上角出现「‹」**返回首页按钮**
- 首页 / 章节 / 错题本 / 收藏 / 统计等页面显示**底部导航栏**（首页 / 练习 / 考试 / 错题 / 收藏）

## 二.5、登录与数据同步（本地服务器版）

### 启动方式

```bash
# 1. 确保 MySQL 已启动（服务名 MySQLCC）
# 2. 首次使用先初始化数据库（建库 nisp_quiz + 4 张表）
node server/init-db.js

# 3. 启动服务器（托管网页 + API）
node server/index.js
# → 浏览器打开 http://localhost:3000
# → 同 Wi-Fi 手机访问 http://<本机IP>:3000
```

### 账号体系

| 特性 | 说明 |
|---|---|
| 注册 / 登录 | 登录页二合一，用户名 2-20 位，密码 ≥ 6 位 |
| 密码存储 | **SHA-256 + 随机盐哈希**，数据库不存明文，登录用常量时间比较 |
| 记住密码 | 默认勾选，登录后 token（30 天）存 localStorage，**期间打开直接跳过登录页** |
| 登录日志 | 每次登录记录 IP、User-Agent、时间（login_logs 表） |
| 数据同步 | 进度 / 错题 / 收藏 / 考试历史 / 统计，答题后 1.2s 自动推送到 MySQL |
| 离线降级 | 服务器未开启时自动进入离线模式（localStorage），不影响刷题 |
| 退出登录 | 学习统计页底部「退出登录」 |

### 数据表

- `users`：账号（用户名 / 哈希 / 盐 / 最后登录 IP 与时间）
- `login_logs`：每次登录的 IP、设备、时间
- `tokens`：30 天免登录令牌
- `user_state`：用户刷题数据整包 JSON（最后写入胜出）

> ⚠️ `server/config.json` 含数据库密码，已加入 `.gitignore`，**不会推送到 GitHub**。

## 四、如何运行

### 方式 A：直接双击 index.html

1. 进入项目根目录
2. 双击 `index.html`
3. 浏览器（推荐 Chrome / Edge / Safari 最新版）打开即可

> 部分浏览器（如 Chrome）对 `file://` 协议下的 `localStorage` 有限制。如果遇到页面空白或脚本加载失败，请改用方式 B。

### 方式 B：用本地 HTTP 服务器（推荐）

在项目根目录执行任选一种：

```bash
# 方案 1：Python 内置
python -m http.server 8080

# 方案 2：Node.js
npx http-server -p 8080

# 方案 3：PHP
php -S 127.0.0.1:8080
```

然后在浏览器访问：<http://127.0.0.1:8080>

## 六、扩展题库

### 直接修改 `data/questions.js`

1. 打开 `data/questions.js`，顶部是注释，往下是 `window.QUESTIONS_RAW = [ ... ]`
2. 在数组末尾追加新的题目对象，格式如下：

```json
{
  "id": "q523",
  "originalId": 523,
  "subject": "nisp",
  "chapter": "第六章 安全运营与应用",
  "type": "single",
  "stem": "题目题干内容……",
  "options": [
    { "label": "A", "text": "选项 A 文字" },
    { "label": "B", "text": "选项 B 文字" },
    { "label": "C", "text": "选项 C 文字" },
    { "label": "D", "text": "选项 D 文字" }
  ],
  "answer": ["B"],
  "analysis": "答案解析：……"
}
```

- **单选题**：`answer: ["A"]`
- **多选题**：`answer: ["A", "C"]`，必须是合法选项 label
- **判断题**：用 `type: "judge"`，答案为 `["A"]`（对）或 `["B"]`（错）

3. 保存后刷新浏览器即可看到新题目。

### 从 PDF 重新生成

`data/questions.js` 是由 `.workbuddy/memory/parse_questions.py` 从 PDF 自动解析生成的。
如果你有新的 PDF，可参考脚本中的正则重新抽取：

```bash
python .workbuddy/memory/parse_questions.py
```

## 十、Hash 路由

| 路径 | 视图 |
|---|---|
| `#/home` | 首页 |

## 十一、已知限制

1. **图片题**：题库中如有插图，本版本不展示图片（仅展示题干 / 选项 / 解析）
2. **多选题**：题库共 8 道多选题，作答时不强制「至少选 2 项」校验，按提交内容判定
3. **跨设备同步**：数据仅存本地 `localStorage`，无账号体系，无法跨设备同步
4. **首次加载**：`data/questions.js` 约 530 KB，建议用本地服务器方式运行
5. **错题移除时机**：错题本中的题目不会因为「重新答对」自动移除，需手动移除或清空
